{% comment %}The file preview dialog of the download page (issue #311; the mock is docs/ui-design/mocks/file-preview.html). Design system 10.9: the confirmation modal's overlay and panel, wider. Driven by the `ftPreview` Alpine component (static/file_transfer/js/preview.js), which reads the previewable files from `#ft-previews`. Focus moves to Close when it opens, stays inside it and goes back to the button that opened it; Escape, the backdrop and Close close it; Left and Right (or Previous and Next) move among the previewable files only. What is shown is chosen by the kind the server gave the file, never by its name. Text is put in the page with `x-text` (textContent): it is never HTML.{% endcomment %}
