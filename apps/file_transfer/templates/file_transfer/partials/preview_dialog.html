{% comment %}The file preview dialog of the download page (issue #311; the mock is docs/ui-design/mocks/file-preview.html). Design system 10.9: the confirmation modal's overlay and panel, wider. Driven by the `ftPreview` Alpine component (static/file_transfer/js/preview.js), which reads the previewable files from `#ft-previews`. Focus moves to Close when it opens, stays inside it and goes back to the button that opened it; Escape, the backdrop and Close close it. Keys: Left and Right (or Previous and Next file) move among the previewable files only; Page Up and Page Down (or Previous and Next page) move among a document's pages; none of them inside the text areas, where the arrows scroll. A preview is a SAMPLE, never the file: a smaller version of an image, smaller pages of a PDF (built lazily, hence "Preparing preview..."), the first 64 KB of a text file. "View full image / document" counts as a download. What is shown is chosen by the kind the server gave the file, never by its name. Text is put in the page with `x-text` (textContent): it is never HTML.{% endcomment %}

Left and right arrow keys switch files. Page up and page down switch the pages of a document. Escape closes the preview.
