{% load color_schemes %}{% comment %} The account page's "Appearance" form: the theme (system, light, dark) and the colour scheme. `theme_form` (a `ThemeForm`) is only passed back with errors. The saved theme is read from `request.user`. A choice submits straight away (htmx, `change`). On success the server answers `HX-Reswap: none` -- the radios stay in place, so the keyboard focus isn't lost -- and an `HX-Trigger: themeChanged` event (the theme and the scheme) that `core/base.html` applies to the page, no reload. Only an error (422) is swapped in, over the form (`hx-target="this"`). `hx-sync` runs one request at a time and keeps only the last click queued, so clicks in quick succession save in order. Without JavaScript the Save button, shown only then, does the same with a normal POST and redirect. {% endcomment %}
