A choice submits straight away (htmx, `change`), like the theme: on success the server answers `HX-Reswap: none` so the dropdowns stay in place and keep the keyboard focus; only an error (422) is swapped in, over the form (`hx-target="this"`). Other pages show the new format when they next load. `hx-sync` runs one request at a time and keeps only the last click queued. Without JavaScript the Save button, shown only then, does the same with a normal POST and redirect. {% endcomment %} {% load display_formats %}
