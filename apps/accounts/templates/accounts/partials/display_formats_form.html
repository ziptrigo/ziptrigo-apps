{% comment %} The account page's date and time format form (issue #245), in the Appearance section. `formats_form` (a `DisplayFormatsForm`) is only passed back with errors. The saved choices are read from `request.user`. A choice submits straight away (htmx, `change`), like the theme: on success the server answers `HX-Reswap: none` so the radios stay in place and keep the keyboard focus; only an error (422) is swapped in, over the form (`hx-target="this"`). Other pages show the new format when they next load. `hx-sync` runs one request at a time and keeps only the last click queued. Without JavaScript the Save button, shown only then, does the same with a normal POST and redirect. {% endcomment %} {% load datetime_format %}
