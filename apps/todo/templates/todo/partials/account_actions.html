{% comment %} To-do's block of the account page's "App actions" (`apps.core.app_actions`, issue #326): Download files (the zip export of the files attached to tasks and comments) and Export XLSX (the task list as a spreadsheet), both of the tasks created in a range. The form is a plain GET to the XLSX; the Download files button fetches the dialog into #todo-export-modal with the same fields (`hx-include`). The dialog is the `fragmentModal` component of `core/js/fragment_modal.js`, which the provider asks core to load (`AppActions.scripts`). Custom shows the two date fields; hidden they are disabled, so they aren't sent. Everything here has its own `todo-` ids, so it can't collide with Receipts' block, which sits on the same page. {% endcomment %}
