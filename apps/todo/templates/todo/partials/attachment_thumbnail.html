{% comment %} A small preview of an image attachment (issue #344), under its row: a link that opens the image like "Open". Needs `file` (an uploaded Attachment) and `frozen` (the account's storage is paused: no thumbnails then). Only a file with `file.has_thumbnail` (bytes sniffed as an image, not over the size cap) gets one. The link is not a tab stop and is hidden from assistive technology: **Open** in the row is the keyboard and screen-reader path to the same image, so the thumbnail is only a mouse shortcut. The `src` is the thumbnail endpoint, which redirects to a short-lived presigned URL, so nothing here goes stale when htmx re-renders the list; the browser scales the full image. {% endcomment %} {% if file.has_thumbnail and not frozen %} {% endif %}
