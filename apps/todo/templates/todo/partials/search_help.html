{% comment %} The "?" popover that explains the search syntax. Put it inside any element; it carries its own Alpine state. `help_id` makes the popover's id unique when it appears twice on a page. {% endcomment %}
  • * matches any text, ? matches one character: pay*rent finds "pay the rent".
  • A word matches anywhere in a word: rent also finds "parent".
  • A task number (1000 or #1000) also finds that task.
  • /.../, or the Regex box, reads the text as a regular expression. It is matched against the normalised text: lower case, no accents, punctuation as spaces. Letters you type are lower-cased for you (not escapes such as \D); write the pattern without accents.
  • Regular expressions share the common syntax of Python and PostgreSQL: no backreferences, lookarounds, atomic groups, possessive quantifiers or named groups.
  • Case, accents, punctuation and formatting are ignored.
  • Deleted comments and earlier edits are not searched.
