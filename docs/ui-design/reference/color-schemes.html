Color schemes

The site's eight colour schemes, each a 10-step accent scale plus its own tinted neutral scale, so every scheme works in light and dark with the same component recipes (primary button = accent 300 with dark text, links and active states = accent 600; Midnight and Graphite use a dark button with a white label in light mode). The values are generated from apps/core/color_schemes.py. Click a scheme to load it into the mock below.
