Contrast

WCAG 2.x ratios. 4.5:1 is the minimum for body-size text.

gray-500 on white4.83
red-600 on white4.83
  • Text on a sage button is always text-gray-900. Never white.
  • Sage-coloured text on light backgrounds is text-sage-600; in dark mode dark:text-sage-300.
  • sage-300 on white is fine for non-text: focus rings, borders, checkbox fill, icons next to a label.

Vertical rhythm

gap-3between buttons
mb-4 / gap-4between fields; toolbar and field-row gaps; message slot
mb-6 / mt-6form title; before form actions; preview row

Containers

All pages: container mx-auto px-4 py-8 plus a max width.

max-w-4xl: list / dashboard
max-w-3xl: form, product intro
max-w-md: auth card, modal panel

Responsive

  • sm: (640px) is the breakpoint that matters. Mobile-first.
  • Field rows: flex flex-col sm:flex-row sm:items-end gap-4.
  • List: px-4 sm:px-6, card corners sm:rounded-md (edge to edge on phones).
  • List item content: md:grid md:grid-cols-2 md:gap-4.
