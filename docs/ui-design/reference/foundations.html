  • Text on a sage button is always text-gray-900. Never white.
  • Sage-coloured text on light backgrounds is text-sage-600; in dark mode dark:text-sage-300.
  • sage-300 on white is fine for non-text: focus rings, borders, checkbox fill, icons next to a label.

Typography

Figtree for text (font-sans, the default), IBM Plex Mono for codes and addresses (font-mono), tabular-nums where digits line up. Self-hosted; Tailwind's scale only. If the font files are missing the system stack shows instead.

Containers

All pages: container mx-auto px-4 py-8 plus a max width.

max-w-4xl: list / dashboard
max-w-3xl: form, product intro
max-w-md: auth card, modal panel

Responsive

  • sm: (640px) is the breakpoint that matters. Mobile-first.
  • Field rows: flex flex-col sm:flex-row sm:items-end gap-4.
  • List: px-4 sm:px-6, card corners sm:rounded-md (edge to edge on phones).
  • List item content: md:grid md:grid-cols-2 md:gap-4.

Radius & elevation

The radius grows with the element: a pill is round, a control 8 px, a container 12 px, an overlay 16 px.

Motion

Motion answers an action and is over before you notice it. Five durations (press 90, hover 150, enter 200, exit 140, modal 220 ms) and two easings, defined as CSS variables in core/css/site.css; all of them drop to zero under prefers-reduced-motion. Try the samples below.

btn: hover darkens one step, press scales to 98%. Tab to it: the ring shows for the keyboard only.
Copy: the check pops (animate-pop), the label says Copied for two seconds.
Thumbnail: group-hover:scale-110, 150 ms.
TokenValueUsed for
--d-press90 msButton press
--d-hover150 msHover colour, border, shadow
--d-enter200 msMenus, flash messages, rows, tab indicator
--d-exit140 msAnything leaving (always faster than it arrived)
--d-modal220 msModal backdrop and panel
--d-moment480 msThe landing page reveal, the only motion that starts by itself

Modals fade in 220 ms and the panel rises 8 px from 97%; they leave in 140 ms. See Components → Confirmation modal.
